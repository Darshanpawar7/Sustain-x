Read it top to bottom. The ESP32 makes every safety decision itself, so the valve closes on a critical leak even without Wi-Fi. Then two paths leave the board: MQTT for the live view, status and commands (blue), and HTTPS for storing every reading (teal). The dashboard listens to both. If a campus network blocks MQTT, storage over HTTPS still works and the dashboard falls back to the database’s live stream.
