FlowState Wiring Guide

Which wire goes where, checked against the firmware in flowstate_config.h. Unplug the USB cable while you wire.

✓ The pin choices are correct.

No pin is a boot, flash or input-only pin, the level sensor uses an ADC pin that still works with Wi-Fi on, and no two parts share a pin. Follow the four rules below and the wiring is safe.

Four rules before you start

1. Flow sensors need a level converter

Their signal is 5 V; ESP32 pins take 3.3 V. Wire each yellow signal through a 4-channel logic level converter.

2. Small sensors run on 3V3

The clock, humidity and level sensors go to 3V3, never 5 V, so their signals stay safe.

3. The servo gets its own 5 V supply

Use a separate 5 V 2 A adapter. Powering it from the ESP32 makes the board restart when the valve moves.

4. One shared ground

Every GND (board, sensors, converter, servo adapter) connects together.

Breadboard layout

One full-size breadboard (60 columns, rows a–j). The ESP32 lies across the centre gap in columns 1–15 with the USB port on the left. Each column's five holes (a–e, and f–j) are connected, so a jumper can go in any free hole of the pin's column.

Top rails = 5 V

Top red (+) is fed from VIN. Only the flow sensors and the converter's HV side use it.

Bottom rails = 3.3 V

Bottom red (+) is fed from 3V3. Clock, DHT22, level sensor and converter LV use it.

Both blue rails = GND

Join them with one black jumper at column 60, so all grounds are shared.

If your ESP32 covers every hole in its columns, use two breadboards side by side with the board bridging them. Everything else stays the same.

Pipe order

Tank→ Flow sensor 1→ Valve→ Leak test point (T-joint)→ Flow sensor 2→ Tap

Opening the T-joint lets water escape between the sensors, which is how you demonstrate a leak.
